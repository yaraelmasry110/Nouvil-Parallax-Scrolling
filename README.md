# Nouvil – Parallax Scrolling Website

## About
A front-end web project that creates a parallax scrolling effect using HTML, CSS, and JavaScript.

## Features
- Parallax scrolling effect for background images.
- Animated moon, mountains, river, and boat elements.
- Responsive viewport setup.
- Navigation bar with hover effects.
- Gradient background and layered visual elements.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Make sure all image files are in the correct folder.
3. Open `index.html` in a web browser.

## Project Purpose
Practice working with DOM elements, CSS positioning, and scroll-based animations in JavaScript.
